# Образец: справка навыка (skills/<навык>/references/<тема>.md)

Эталон — `plugins/supertick/skills/team-feature/references/team-runtime.md`: вступление в три
строки, разделы-правила, у каждого правила причина (замер или случай из прогона).

```markdown
# <Тема>

<2–3 строки: о чём справка и откуда её значения. Корень плагина `{plugin}` — строка
`Plugin root:` из state.md.>

## <Правило или процедура — существительное, не «Шаг N»>

<Что делать. Если это порядок действий — нумерованный список.>
1. <действие с командой `python3 {plugin}/scripts/<скрипт> …`>
2. <действие>

<Почему: дата, карточка, что сломалось без этого правила — одной фразой.>

## <Следующее правило>

<Ссылка на соседнюю справку — `phase2-monitoring.md, «Второе мнение»` (файл и заголовок).>
```

Правила справки:
- Команды — с `{plugin}` и `<RUN DIR>`; абсолютные пути машины не пишутся.
- Шаблоны, которые читает тик (`## Task <id>:`, `Status:`, `## Phase:`, шапка письма), не
  переводятся и не украшаются — их разбирают `plan_tasks`, `state_phase`, `read_mail`.
- Ссылка на другой файл — «`файл.md, «Заголовок»`»; номер строки уезжает при первой правке.
- Потолок длины файла — в `checks/commands.md`, «Потолки длины».
