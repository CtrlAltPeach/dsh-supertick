# Добавка в файл, который стоит на потолке длины

У файлов плагина есть потолки непустых строк (`checks/commands.md`, «Потолки длины»). На
22.10.2026 (0.19.0) ровно на потолке стоят `coder.md` 220, `proxy-teammate.md` 300,
`unified-reviewer.md` 250, `engines.md` 450, `phase2-monitoring.md` 280; в шаге от него —
`tech-lead.md` 158/160. Любая новая строка в файл на потолке — нарушение критерия.

Плохо — дописать правило и не посчитать:

```bash
echo '- новое правило' >> plugins/supertick/agents/coder.md   # 221/220
```

Хорошо — добавка вместе с сокращением в том же файле, счёт до REVIEW:

```bash
grep -cv '^\s*$' plugins/supertick/agents/coder.md            # 220 — не больше потолка
```

Почему: потолок — потолок, не цель. Сокращай слова, а не факты (см.
`avoid-losing-a-rule-on-rewrite.md`): ловушка без даты или без правила — уже потеря. В handover
напиши, что файл снова на потолке.
