# Литерал чужого типа агента в plugins/supertick

Шаг CI «No foreign plugin types» грепает `agent-teams:` по всему `plugins/supertick` — в коде,
в комментариях, в прозе. Ему всё равно, что это не тип агента, а фраза «линии agent-teams: 0.17».
21.10.2026 (решение L1) при переносе `team-wait.sh` в комментарий версии дописали «с 0.17.0 линии
agent-teams:», чтобы указать происхождение, — шаг 4 стал красным; строку вернули как в источнике,
`cmp` 7/7.

Плохо:

```markdown
Если тип неизвестен, можно взять agent-teams:coder.
# team-wait.sh — из линии agent-teams: 0.17
```

Хорошо:

```markdown
Неизвестный тип — `QUESTION` ведущему; спавнятся только `supertick:<роль>`, встроенные
`general-purpose` и `Explore` — лишь у ролей из «Шаг 0b: движки».
```

Почему: запрет записан проверкой, а не словами. Хочешь сослаться на исходный плагин — пиши его
имя без двоеточия после, и не в `plugins/supertick`. Перенесённые побайтно скрипты не правь вовсе —
кроме двух, изменённых в 0.18.1 (прогон feature-trial-medium): `supervisor-tick.py` и
`team-wait.sh`. Их правят только с тестом в `tools/tests`, и запрет литерала действует и в них.
