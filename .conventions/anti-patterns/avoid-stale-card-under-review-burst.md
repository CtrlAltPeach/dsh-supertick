# Карточка рецензента не обновлена при пачке REVIEW

Тик считает письмо недоставленным (`undelivered_mail`), если оно лежит 2 минуты, а карточка
адресата старше письма. 21.10.2026 (L20) пять REVIEW пришли подряд; рецензент читал диффы по
очереди и карточку переписал только после первого вердикта — тик дал ложный P0, хотя ревью шли.

Плохо — карточка переписывается после ревью:

```text
пришли REVIEW 18, 19, 20, 21, 22 → читаю дифф 18 … вердикт 18 → карточка → дифф 19 …
```

Хорошо — на КАЖДЫЙ пришедший REVIEW, до чтения диффа, Write карточки целиком
(`<RUN DIR>/runs/unified-reviewer.json`, у рецензента нет Bash):

```json
{"name": "unified-reviewer", "role": "reviewer", "task": "22", "status": "reviewing",
 "lastEventAt": "<ts письма REVIEW 22 + 1 с>", "note": "очередь: 18,19,20,21,22"}
```

Почему: свежая карточка — единственный для тика признак, что письмо взято. Правило записано в
`agents/unified-reviewer.md`, «Шаг 1 — отметь, что запрос взят»; время — по разделу «Время без
часов» того же файла.
