# Перевод вместо фактов (чистая комната)

Близкий русский пересказ английского абзаца даёт 0 общих 8-грамм и 0 общих строк — и всё равно
остаётся переводом (риск R2). Первая попытка задачи 4 провалила приёмку: спецификация
proxy-teammate шла по шагам исходника в том же порядке, фраза за фразой. Канал заголовков `##`
тут не поможет — русские заголовки с английскими не совпадают никогда (решение L5).

Плохо — структура и порядок источника, переведённые по предложению:

```markdown
## Шаг 0 … ## Шаг 4 … (разделы и их порядок — как в исходнике)
Сначала прокси делает A. Затем он делает B, потому что C. После этого …
```

Хорошо — факты короткими пунктами, порядок и разделы свои:

```markdown
## Что уходит в движок
- бриф роли + дифф файлом (`<RUN DIR>/engine/<role>-<n>.diff`), абсолютные пути
- лимит: один повтор, затем `ENGINE_DOWN: <роль>. <причина>`
```

Почему: сверка (`tools/run_overlap.sh`) ловит совпадение слов, канал якорей — одинаковую
последовательность путей и чисел; перевод с новыми словами проходит первое и виден только по
второму и глазами. Каждое окно якорей либо переписать, либо обосновать в `docs/clean-room.md`.
